# Learning Platform with Smart Study Planner

## Overview
Learning Platform with Smart Study Planner is a frontend web application developed using HTML, CSS, and JavaScript. It helps students manage courses, create study plans, track learning progress, and save personal notes.

## Features
- Home Dashboard
- Course Listing
- Course Enrollment
- Smart Study Planner
- Progress Tracking
- Notes Management
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure
```
project/
│
├── index.html
├── courses.html
├── enroll.html
├── planner.html
├── progress.html
├── notes.html
├── logout.html
├── style.css
└── app.js
```

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your web browser.
